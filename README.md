![TokenBubble](tokenbubbleicon.png)

Codex and Claude subscription usage in your Windows tray.

[Download for Windows](https://github.com/cloudboy-jh/tokenbubble/releases)

Unzip. Run `tokenbubble.exe`. Click the bubbles icon near the clock, under **Show hidden icons** if needed.

Uses your existing Windows Codex or Claude Code sign-in.

## Development

Windows PowerShell, with Rust installed:

```powershell
cargo dev
```
